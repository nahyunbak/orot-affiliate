# IAP 가격 비율 참고

사용자 요청에 따라 원본 [`mobile/csv/app-price.csv`](../mobile/csv/app-price.csv)를 보존합니다. 기존 `basePlanId`와 국가별 가격은 과거 제품의 참고 자료이며 새 앱의 확정 가격이나 상품 설정이 아닙니다.

같은 통화·기준 요금제를 정한 뒤 `대상 가격 / 기준 가격`으로 상대 배수를 구하고 새 기준 가격에 그 배수를 적용하는 참고용으로 사용하세요. 통화가 다른 숫자를 그대로 나누면 환율 차이가 섞이므로 같은 통화끼리 비교하거나 동일 시점의 환율로 환산해야 합니다. 세금·스토어 가격 단계·지역 정책도 별도 확인해야 합니다.

자동 가격 업로드의 입력으로 원본을 그대로 사용하지 마세요. 자신의 상품·base plan ID와 지원 국가·통화·가격을 별도 검토하고, 스토어의 현재 설정을 조회한 뒤 dry-run 결과를 확인하세요. 이 작업에서는 가격 업로드나 실제 과금을 실행하지 않았습니다.
